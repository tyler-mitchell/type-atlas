# `@type-atlas/core`

The headless Type Atlas API owns workspace-scoped code-intelligence operations,
language-server lifecycle, source folding, and agent-oriented text rendering.
It is the implementation layer used by `@type-atlas/mcp`.

Most users should install the
[Type Atlas MCP server](https://github.com/tyler-mitchell/type-atlas#install).
This package is intended for integrations that need to embed the same
operations without MCP transport.
